# 深蓝随便签 StickyBoard · v16.3 （本地版）
---
一个**单文件、零安装、完全离线**的桌面便签应用：所有功能装在一个 `.html` 里，双击即用。数据只存在你自己的浏览器里，不经过任何服务器。

---

## 一、快速开始

| 平台 | 打开方式 |
|---|---|
| **Windows / macOS** | 解压 zip → 双击 `便签台.html`（推荐最新版 Chrome / Edge；老版本浏览器也兼容至 ES2017） |
| **安卓** | 解压后用 Chrome/Edge/系统浏览器「打开文件」；微信里打开请点右上角 →「在浏览器打开」 |
| **iOS** | Safari 不能开本地 html。用 Alook、Documents by Readdle 等支持本地网页的 App 打开；或直接用线上版（功能相同，可添加到主屏幕） |

> ⚠️ **数据跟"浏览器 + 文件路径"绑定**：同一浏览器、同一位置打开同一份文件 = 同一份数据。换浏览器或把文件挪了位置，看到的会是空白板——用「导出 / 导入」搬数据即可（见第六节）。

## 二、界面总览

```
┌ 工具栏：  ⊕新建   搜索框(⌘K)   ☑只看待办   折叠全部   明暗切换   ?帮助 ┐
│                                                                     │
│        （ 墙面：任意拖放的便签卡片 ）                                  │
│                                                                     │
└ 墙底架：[已归档 n 张] · 25 张便签 · 3 个待提醒 · 8 待办 · #工作(12) #紧急(5) … └
```

- **标题栏**（每张卡顶部）：📌 置顶 | 🎨 语法主题 | ⋯ 更多（颜色/日期/提醒/折叠/复制/关联/归档/导出/删除）。按住标题栏空白处拖动 = 移动整张卡
- **墙底架**：归档收纳 + 全墙统计 + 标签筛选条（一行内居中，用 `·` 分隔）

## 三、写便签

- **双击卡片**进入编辑，`Enter` 提交 / `Esc` 放弃编辑；折叠状态下双击标题栏也可展开编辑
- 支持 Markdown 子集：`#` 标题（1-3 级）· `**粗***斜~~删~` · `> 引用` · `- 列表` · `1. 有序` · `` `代码` `` 与 ```代码块``` · `---` 分隔线 · 表格 · 链接 `[文字](https://…)` · **任务清单**：
  ```
  - [ ] 未完成事项
  - [x] 已完成事项（预览里可直接点勾选框切换）
  ```
- 首行自动成为卡片**标题**（折叠/归档陈列/导出文件名都用它）

## 四、提醒

1. ⋯ → 「提醒」选日期时间 → 到点弹**系统通知**（首次会请求通知权限），页内 toast + 提示音兜底
2. 到点瞬间：卡片呼吸光晕约 4 秒（1s × 4 次）
3. **到点后未处理：时钟徽标红色常亮**（展开卡在页脚 / 折叠卡在标题栏）；在 ⋯ 里清除或改期提醒即解除
4. 应用没开着也不怕：错过的提醒在下次打开时汇总补通知；30 天未动的卡自动**沉淀淡出**

## 五、置顶 / 折叠 / 归档 / 整理

- **📌 置顶**：卡片永远浮在最上层（压过其他窗口层级逻辑）
- **折叠**（标题栏左侧箭头 / 工具栏折叠全部）：收成一条标题栏，长文便签的救星
- **归档**：⋯ → 归档收到墙底架；架内卡片**提醒照常准点唤回**；「全部放回」一键恢复；支持搜索时命中归档卡自动唤醒
- **沉淀入架**：30 天未动的卡进底栏时出现「沉淀 n 张 → 入架」一键收纳
- **整理到顶部**：工具栏 ↑↓ 按钮把所有卡自动铺成整齐的置顶网格
- **关联连线**：⋯ →「关联到…」再点另一张卡 → 出现连线，点线断开

## 六、导出与导入

### 单卡导出（v16 起）
点卡片标题栏的 **⬇ 保存按钮** → 选 `另存为 Markdown（.md）` 或 `另存为纯文本（.txt）`，文件名自动取标题。

### 全量备份 / 迁移
- 工具栏 ↑ = **导出全部**（.json，含所有便签+布局+主题+归档）
- 工具栏 ↓ = **导入**（先预览影响再确认，不会静默覆盖）
- 💡 换电脑/换浏览器：旧环境导出 → 新环境导入，一步搬完
- 便签很多天没备份时，导出按钮旁出会⚠红点提醒

## 七、标签（轻量玩法，无需输入框）

- 正文任意位置写 `#工作 #紧急` → 保存即自动打标（中英文、`-`、`.` 均可；`#` 后**不能有空格**，有空格按 Markdown 标题处理）
- **墙底架实时聚合**：`#工作(12)`，数字 = 使用张数（含归档卡，v15.1 起）
- 点标签筛选：**可多选，AND 语义**（同时包含才亮）；再点取消、`清除 ✕` 全清
- 命中的已归档便签会**自动唤回桌面原位**（v16.2，与搜索行为一致）
- 行内代码 `` `#工作` ``、代码块内的 `#`、URL 锚点 `page#frag`、纯数字 `#123` 都**不算标签**
- 标签不落库、纯派生：删除/编辑/导入导出后自动重算，零维护

## 八、搜索

顶部搜索框支持组合语法（空格分词取交集）：

| 语法 | 作用 |
|---|---|
| `关键词` / `#标签` | 匹配正文与标签 |
| `[]` | 只看含未勾选任务清单的卡 |
| `!due` | 只看已过期未读的提醒 |
| `c:黄` / `c:yellow` | 按纸色筛选（色名或 hex） |

示例：`报销 [] c:黄` ＝ 黄色卡里带未完成待办、内容含"报销"的。
搜索命中**墙底架里的归档卡也会自动放回墙面**并高亮。

## 九、语法配色主题（MarkText 风格）

- 🎨 按钮（每张卡标题栏 & 面板）：本卡四选一 **跟随全局 / 纸色（关）/ One Dark / Gruvbox Light**
- 全局选项（任一张卡 🎨 → 下半区）：`自动` = 浅色界面走 Gruvbox、深色界面走 One Dark；**默认「纸色（关）」**——不染色，开箱即用
- 色值 1:1 取自 marktext 官方 one-dark / gruvbox-light 主题（标题 1-6、粗斜、引用、code、表格等 18 个语义 token）
- 单卡选择优先于全局；所有选择自动持久化

## 十、快捷键一览

| 键位 | 动作 |
|---|---|
| `⌘/Ctrl + N` | 新建便签（落点自动找空位级联） |
| `⌘/Ctrl + K` | 聚焦搜索框 |
| `?` | 打开帮助面板 |
| 卡片编辑中 `Enter` / `Esc` | 提交 / 放弃 |
| `Del`（选中卡片时） | 删除当前卡（可从撤销 toast 找回最近一张） |
| 双击标题/正文 | 进入编辑 |
| 点预览中的复选框 | 勾选/取消任务 |

## 十一、数据安全与隐私

- 100% 本地：不加载任何远程脚本/字体/图片，断网可用
- 数据在浏览器 `localStorage`（键名带版本号，浏览器大清理会带走它——**勤用导出**）
- 关页面前自动冲刷待写入数据，防丢最后一笔
