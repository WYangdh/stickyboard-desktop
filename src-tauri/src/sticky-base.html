快捷键 & 小贴士

  • ⌘/Ctrl+N新建便签
  • ⌘/Ctrl+K聚焦搜索
  • Del删除选中的便签（可在 Toast 中撤销）
  • Esc取消编辑 / 关闭菜单 / 取消选中
  • ?打开本窗口
  • 拖把手移动，拖右下角改大小；最左 ◀ 箭头收起便签——只留一行标题（内容第一行），再点展开。
  • 正文是 Markdown：双击进入编辑，失焦自动渲染。支持 # 标题、**粗体**、*斜体*、~~删除~~、列表、- [ ] 任务清单（可点勾）、> 引用、\`代码\`、链接。
  • 表格：| 名称 | 价格 | + |:--|--:| 对齐行，单元格支持行内语法，可转义竖线。图片：![说明](https://…/a.png) —— 仅 http/s，自动限宽。
  • ⋯ 菜单：换颜色 / 设提醒 / 置顶 / 复制 / 删除。到点提醒 = 系统通知 + 提示音 + 脉冲；未授权自动降级为页内提醒。
  • 工具栏 ↑/↓ 导出/导入 .json（导入先预览影响再确认）；10 张以上久未备份，导出键亮红点。
  • 标签：正文写 #工作（#后直接跟文字，中英文皆可）即自动打标签；底栏点标签筛选，可多选（同时包含）；搜索词也会命中标签；`#码内` 与代码块里的 # 不算标签。
  • 搜索符号：[] 含未完成任务 · !due 过期未读 · c:色名 按颜色，可与文字叠加；☑ 按钮只看待办。30 天未动的卡自动沉淀淡出。
  • 关联：⋯ 菜单「关联到…」再点另一张，两点出现连线；点线即断开。
  • 归档：⋯「归档这张」或墙底架子「沉淀 N 张 → 入架」收走陈旧便签；点架子展开回看、单击回位；搜索命中或提醒到点自动回位，批量操作不碰入架卡。
